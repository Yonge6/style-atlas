# 虾子曰艺术风格图鉴 1.3

## Theme

看懂一种美 / Understand a Style

## Vision

让普通人不需要艺术或设计背景，也能通过一张图逐渐理解：

- 颜色
- 构图
- 光影
- 线条
- 材质
- 节奏
- 情绪
- 文化气质

## V1.3-A

- 重构详情页信息架构
- 建立沉浸式看图引导
- 完成 12 个代表风格的双语增强内容
- 为其余 108 个风格保留稳定、诚实的基础体验
- 增加仅保存在本机的审美感受记录
- 不调整付费商品、价格、权益或 StoreKit

## V1.3-B

- 人工审核并扩展更多风格的增强内容
- 优化相似风格的具体辨析
- 根据内容审核成本决定是否覆盖全部 120 个完整 guide

## Non-goals

本版本不做：

- 每日一美
- 课程
- 签到
- 连续学习
- 积分
- 勋章
- 排行榜
- 登录
- 后端
- 云同步
- 社区
- 评论
- AI 图片生成
- AI 聊天
- 新 IAP
- 新订阅
- 推送通知

## Release Boundary

- iOS 1.2 Build 9 的发布基线和 `ios-v1.2.0-build9` 标签保持不变。
- V1.3-A 仅在 `feature/v1.3-style-deep-dive` 开发和验收。
- 产品验收前不合并 `main`，不修改 Version 或 Build，不生成 Archive，不上传新 Build。
