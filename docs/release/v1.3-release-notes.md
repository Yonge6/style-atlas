# Style Atlas V1.3 Release Notes

## 中文

虾子曰艺术风格图鉴 V1.3 带来更深入的风格探索体验：

- 72 种风格现已提供完整审美导览
- 从“看见”到“看懂”，引导观察构图、色彩、线条与情绪
- 新增风格识别、审美画像、日常观察与相近风格对比
- 优化详情页阅读、导航与大字体体验
- 提升稳定性与无障碍体验

## English

Style Atlas V1.3 makes it easier to look closely and understand what gives a visual style its character:

- Complete aesthetic guides are now available for 72 styles
- Guided observations highlight composition, color, line and mood
- New recognition cues, taste profiles, everyday observations and style comparisons
- Improved detail-page reading, navigation and larger-text support
- Stability and accessibility refinements
