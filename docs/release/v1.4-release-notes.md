# Style Atlas V1.4 Release Notes

## 中文

虾子曰艺术风格图鉴 V1.4 带来更清晰、更沉浸的风格学习体验：

- 全新设计风格详情页，保留原图比例并提升阅读层级
- 统一导航、收藏、分享、复制与锁定状态的图标语言
- 优化 Plus 内容预览，更直观地展示完整学习路径
- 重构菜单与联系入口，查找收藏和下载 App 更顺畅
- 改进中英文布局、无障碍与详情直达体验

## English

Style Atlas V1.4 introduces a clearer, more immersive way to understand visual styles:

- A redesigned style detail experience with original-ratio artwork and stronger reading hierarchy
- A consistent icon system for navigation, saving, sharing, copying, and locked states
- A richer Plus preview that reveals the complete learning path before purchase
- A refined drawer for favorites, contact, related projects, and App Store access
- Improved bilingual layouts, accessibility, and direct links to detail sections
