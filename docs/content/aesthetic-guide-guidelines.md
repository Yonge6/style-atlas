# Aesthetic Guide Content Guidelines

## Purpose

帮助普通创作者看见具体画面线索，并形成自己的审美语言。内容提供观察入口，不提供唯一答案。

## Voice

- 中文自然、具体，像策展人在画前轻声提醒。
- 英文是自然改写，不逐字翻译中文句法。
- 少用学术术语；必须使用时，紧接可见画面解释。
- 不使用“高级感”“很有艺术感”等空泛结论。
- 不命令用户喜欢某种风格，也不把偏好分高低。

## Observation Rules

- 每条观察落到颜色、光影、构图、线条、材质、节奏或情绪。
- 指出“看哪里”和“会看到什么”，避免只列标签。
- openingQuestion 不提前公布全部答案。
- 三个 observe 应有递进，不重复同一特征。
- memoryAnchor 可以形象，但不能替代事实内容。

## Profile Is Not a Score

- level 仅表示该项在画面中的观察倾向，范围 1-5。
- 不计算总分，不排名，不表示质量。
- 每项必须同时有文字解释和可读的 level。
- 完成状态不能只依赖颜色。
- 页面固定说明：“这是观察提示，不是审美评分。”

## Comparisons

- 相似点说明为什么用户会混淆。
- 区别必须具体到网格、轮廓、色彩、材料、叙事或用途。
- comparison `styleId` 必须属于现有 120 个风格。
- 不写“都很现代，但风格不同”一类循环表述。

## Everyday Language

- 完整 guide 覆盖家居、穿搭、摄影和日常物件。
- 给普通人一个可以立即观察的动作。
- 不只改写设计用途，不做购买推荐，不植入商品。
- Fallback 只使用已有 `useCases`，不自动补造日常结论。

## Bilingual Requirements

- 所有用户可见字段必须同时有 `zh` 和 `en`。
- 两种语言表达相同事实和观察意图。
- 专有名词沿用项目现有中英文名。
- 英文避免不自然的机器直译和过长句。

## Accuracy and Safety

- 不编造历史事实或艺术家动机。
- 不使用未经核实的艺术家原话。
- 不鼓励复制具体作品、角色或在世创作者的完整可识别风格。
- 涉及文化传统时，描述可见语言和语境，避免把复杂文化简化成装饰标签。

## Pilot Review Checklist

以下 12 个试点逐项人工审核：

- [ ] swiss-style
- [ ] art-deco
- [ ] impressionism
- [ ] van-gogh
- [ ] chinese-ink-painting
- [ ] ukiyo-e
- [ ] dunhuang-mural
- [ ] islamic-geometric
- [ ] african-tribal-pattern
- [ ] mexican-muralism
- [ ] editorial-illustration
- [ ] solarpunk

每个试点确认：

- [ ] openingQuestion 中英文自然
- [ ] 3 个 observe 具体且递进
- [ ] 4 个 profile level 在 1-5 且文字匹配
- [ ] 3-5 个 feelingWords 不做价值判断
- [ ] 4 个 everydayLife 可执行且不导购
- [ ] 2 个 comparison 引用有效风格且差异具体
- [ ] reflectionPrompt 开放、不诱导唯一答案
- [ ] 无未经核实的事实或引语
